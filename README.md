# 🎮🎬 Lierkour v2.0 — Хранитель пройденных Медиа

**Lierkour** — локальное кроссплатформенное приложение для ведения личной коллекции фильмов, сериалов, аниме и видеоигр.
Пройденные игры, просмотренные киноленты, сезоны, оценки, рецензии, платформы, лаунчеры, цитаты, скриншоты и связи между медиа хранятся в одном
месте — на вашем компьютере. Без обязательной регистрации, без облака и без навязчивого подключения к интернету.

Приложение работает на **Windows** и **Linux**, создано на **Tauri 2**, **React 19**
и **SQLite**. База данных и изображения лежат в обычной локальной папке, которую легко
скопировать, перенести на флешку или заархивировать в один клик.

## Возможности

### 🎬 Фильмы и Кино
- Карточка фильма: название, оригинальное название, режиссёр, год, жанры, страна, хронометраж, IMDb ID, теги, описание и личные впечатления.
- Статусы просмотра кино: **«В планах»**, **«Смотрю»**, **«Просмотрено»**, **«Брошено»**.
- Оценка от 1 до 10.
- Теги через запятую: *«на пересмотр»*, *«с друзьями»*, *«классика»* и любые другие.
- Галерея кадров: сохранение кадров фильма с подписями.
- Любимые цитаты с красивым блочным отображением.
- Интеграция с OMDb API для быстрого заполнения постеров и описаний кино.

### 📺 Сериалы и сезоны
- Поддержка сериалов, мультсериалов и аниме с иерархией сезонов.
- Каждый сезон может быть самостоятельной карточкой с собственным статусом, постером, оценкой и заметками, связанной с родительским тайтлом через `parent_id`.
- На карточке сериала отображается «стопка» сезонов и прогресс.
- Автоматический подсчёт просмотренных сезонов в аналитике.
- Возможность в любой момент отвязать сезон и сделать его отдельным тайтлом.

### 🎮 Видеоигры
- Полноценный учёт игровой коллекции: игры на PC, консолях и портативных устройствах.
- Игровые платформы (PC, PlayStation 5, Xbox Series, Nintendo Switch, Steam Deck и др.).
- Лаунчеры и сервисы дистрибуции (Steam, GOG, Epic Games Store, VK Play, Battle.net, Xbox Game Pass, Эмуляторы и др.).
- Разработчик и издатель (вместо страны).
- Время прохождения (в часах).
- Статусы прохождения видеоигр: **«В бэклоге»**, **«Играю»**, **«Пройдена»**, **«Брошена»**.
- Галерея скриншотов из игр с подписями.
- Игровые заметки, гайды, советы и памятки.

### 🔗 Связи между тайтлами (Relations)
Строгое разделение контекста — фильмы связываются с фильмами, игры связываются с играми:
- **Для фильмов:** сиквел, приквел, ремейк, спин-офф, связь по франшизе/вселенной.
- **Для игр:** продолжение (сиквел), предыстория (приквел), ремейк/ремастер, спин-офф, связь по серии/вселенной.
- Направленные связи: на странице оригинала отображается «Сиквел к...», на странице продолжения — «Приквел к...».
- Быстрый переход к связанному медиа в один клик.
- Автоматическое каскадное удаление связей при удалении тайтла.

### 🎛️ Фильтры и адаптивный поиск
- **Слайдер медиа:** «Все», «Фильмы», «Игры» с моментальной фильтрацией.
- **Контекстные фильтры:**
  - На вкладке «Игры» отображаются только игровые категории и игровые статусы.
  - На вкладке «Фильмы» — категории кино и статусы просмотра.
  - На вкладке «Все» — объединённые списки без риска получить пустую выборку.
- Быстрый регистронезависимый поиск по названию, режиссёру, платформе, лаунчеру, тегам и жанрам.

### 🖥️ Интерфейс и эргономика
- **Навигация жестами:**
  - Боковые кнопки мыши: «Назад» (XBUTTON1) и «Вперёд» (XBUTTON2).
  - Свайп двумя пальцами по тачпаду: вправо — «Назад», влево — «Вперёд».
  - Встроенный debounce/lock для предотвращения инерционного пропуска страниц.
  - Сохранение и восстановление позиции скролла при возврате.
- **Адаптивный хедер:** кнопка «Добавить» и панель действий всегда на виду при любом разрешении экрана; подписи меню лаконично адаптируются на экранах мобильного и компактного формата.
- **Темы:** Тёмная и светлая темы с сохранением выбора.
- **Языки:** Русский и английский интерфейс с переключением на лету.

### 📊 Аналитика коллекции
- Раздельный и общий подсчёт: фильмов, сериалов, сезонов и видеоигр.
- Время, проведённое за фильмами (часы и минуты) и играми.
- Распределение по статусам прохождения и просмотра.
- Топ жанров, топ режиссёров, топ игровых платформ и лаунчеров.
- Средний балл оценок.

### 💾 Резервные копии и переносимость
- **ZIP-архив (`lierkour-backup.zip`)** — полная автономная резервная копия со всеми записями, связями, постерами и скриншотами.
- **Импорт ZIP** — восстанавливает коллекцию, аккуратно сопоставляет связи и игнорирует дубликаты.
- **CSV (`lierkour.csv`)** — табличный экспорт для Excel и Google Таблиц.
- **Markdown (`lierkour.md`)** — красивый каталог для Obsidian, Notion или GitHub.
- Полная совместимость архивов между Windows и Linux.
- **Автоматическая миграция:** при переходе с предыдущих версий (MyFilmLibrary) данные автоматически копируются в каталог Lierkour без потерь.

## Быстрый старт (Разработка)

### Требования
- **Rust stable** (edition 2024)
- **Node.js 22+** и npm
- **Tauri CLI 2**:
  ```bash
  cargo install tauri-cli --version "^2" --locked
  ```

### Запуск в режиме разработки
```bash
git clone https://github.com/LaRevole/Lierkour.git
cd Lierkour

cd frontend
npm ci
cd ..

cargo tauri dev
```

Tauri автоматически запустит Vite на `http://127.0.0.1:5173` и откроет окно приложения с поддержкой Hot Module Replacement (HMR).

## Сборка релизов

### Windows

Из корня проекта выполните PowerShell-скрипт сборки:
```powershell
powershell -ExecutionPolicy Bypass -File packaging/windows/build.ps1
```

Скрипт соберёт production frontend, скомпилирует release-бинарник на Rust и сформирует переносимый пакет в:
```text
dist/Lierkour-windows-x64/
├── lierkour-app.exe     # Обычный запуск (данные в %APPDATA%/Lierkour)
└── run-portable.bat     # Портативный запуск (данные в папке ./data)
```

### Linux

Готовый скрипт сборки:
```bash
chmod +x packaging/linux/build.sh
./packaging/linux/build.sh
```

Готовый пакет будет собран в:
```text
dist/Lierkour-linux-x64/
├── lierkour-app
├── run-portable.sh
└── com.lierkour.desktop
```

## Портативный режим

В портативном режиме база данных SQLite (`library.db`), постеры и скриншоты хранятся в подпапке `data` рядом с приложением.

Переменная окружения для явного указания папки данных: `LIERKOUR_DATA_DIR` (с обратной совместимостью с `MY_FILM_LIBRARY_DATA_DIR`).

- **Windows:** запустите `run-portable.bat`
- **Linux:** запустите `./run-portable.sh`

---

## Расположение системных данных

В стандартном режиме данные хранятся по системным путям:
- **Windows:** `%APPDATA%\Lierkour\`
- **Linux:** `${XDG_DATA_HOME:-~/.local/share}/Lierkour/`

Структура папки данных:
```text
Lierkour/
├── library.db           # База данных SQLite (WAL-режим)
├── posters/             # Оригиналы и миниатюры (thumb_*) обложек
└── screenshots/         # Скриншоты и кадры
```
